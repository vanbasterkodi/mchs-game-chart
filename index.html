Backup

Everything is saved on this iPad only. Make a backup after each game and save it to Files, iCloud Drive, or email it to yourself, so nothing is lost if the iPad's data gets cleared.

GitHub

Upload saves every game, a PDF report for each game, a season report, and a full backup to the data folder of your repo. Load pulls the latest upload onto this device, for example to move games to another iPad. PDF reports also save to data/reports once a token is set.

No token yet? Get a token
GitHub opens with the form filled in. Under Repository access pick Only select repositories and choose mchs-game-chart, then tap Generate token, copy it, come back here and paste it in the Token box.
