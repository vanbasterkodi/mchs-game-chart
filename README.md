# mchs-game-chart
MCHS 2026 season charts

Live chart: https://vanbasterkodi.github.io/mchs-game-chart/

- Open the link in Safari on the iPad, then Share > Add to Home Screen. Always open it from the home screen icon.
- Games are saved on the iPad only (not in this repo). Use Plays > Back up now after each game.
- `index.html` is the whole app. `sw.js` keeps a copy on the iPad so it opens without Wi-Fi.
